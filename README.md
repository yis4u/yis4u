# Tay’s portfolio

A responsive, dependency-free portfolio built with HTML, CSS, and JavaScript.

## Run locally

From this directory:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

The site can also be deployed to any static hosting service. No build step is required.

## Personalize

Edit `index.html` to update the name, introduction, projects, and contact email (`zhenyea@gmail.com`). Project illustrations are CSS-based and require no image assets. Fonts load from Google Fonts, with local fallback fonts when offline.
